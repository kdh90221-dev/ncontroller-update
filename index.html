OBD 방식이 아닙니다. 차 통신을 직접 받아 반응이 빠릅니다

시중 OBD 제품은 진단 단자로 값을 하나씩 물어보고 답이 올 때까지 기다립니다. 띄우는 값이 많을수록 더 느려집니다. V2 · V2X는 차 안에서 오가는 통신을 직접 받아, 차가 값을 보내는 순간 바로 보여 줍니다.

시중 OBD 제품

진단 단자로 값을 하나씩 물어보고 답을 기다립니다. 값이 많을수록 느려지고, 실제보다 한 박자 늦게 따라옵니다.

V2 · V2X

차가 주고받는 통신을 직접 받습니다. 여러 값을 띄워도 느려지지 않고, 회전수 · 속도 · 기어가 순정 계기판 바늘과 함께 움직입니다.

설치 방법

처음 설치하기

사용하는 휴대폰이나 PC를 고르세요.

  1. 내 기기에 맞는 APK를 내려받습니다.

    v1(배기밸브 · 안개등)은 N Controller Mobile, V2 · V2E · V2X는 N Controller v2입니다. 다운로드

  2. 다운로드할지 물으면 「다운로드」를 누릅니다.

    브라우저가 「이 유형의 파일은 기기에 손상을 줄 수 있습니다」 같은 경고가 나와도 그대로 다운로드합니다.

  3. 받은 파일을 눌러 엽니다.

    「출처를 알 수 없는 앱」 설치를 막는 창이 뜨면 「설정」을 눌러 그 브라우저의 「이 출처 허용」(알 수 없는 앱 설치 허용)을 켜고 돌아옵니다.

  4. 「설치」를 누릅니다.

    Play 프로텍트 창이 뜨면 「세부정보 더보기」에서 「무시하고 설치」를 누릅니다.

  5. 앱을 열고 설명서대로 연결합니다.

    N Controller Mobile 설명서 · N Controller v2 설명서

새 앱 버전이 나오면 앱이 알려 줍니다. 앱을 지우지 말고 그 위에 설치해 주세요.

  1. PC 프로그램 ZIP 파일을 내려받습니다.

    v1(배기밸브 · 안개등) 전용입니다. 다운로드

  2. 압축을 풉니다.

    받은 ZIP 파일을 마우스 오른쪽 버튼으로 눌러 「압축 풀기」(또는 「모두 압축 풀기」)를 고릅니다.

  3. N_Valve.controller.Update.exe를 실행합니다.

    「Windows의 PC 보호」 창이 뜨면 「추가 정보」를 누른 뒤 「실행」을 누릅니다.

  4. 컨트롤러를 USB로 연결합니다.

    처음 연결하는 기기라면 신규 등록 창이 뜹니다. 닉네임을 넣고 등록을 마칩니다.

새 프로그램 버전이 나오면 프로그램이 알려 줍니다. 업데이트 중에는 USB 케이블을 분리하거나 PC 전원을 끄지 마세요. 자세한 내용은 배기밸브 · 안개등 설명서를 참고하세요.

  1. App Store에서 Bluefy를 설치합니다.

    아이폰의 사파리 · 크롬은 웹에서 블루투스를 쓸 수 없어 블루투스를 쓰는 웹 브라우저가 필요합니다. 웹은 아이폰 전용입니다.

  2. Bluefy로 열기를 누릅니다.

    Bluefy가 열리며 N Controller 웹이 바로 뜹니다. 직접 넣으려면 Bluefy 주소 칸에 ncontroller.kr/app

  3. 시동을 걸고 「연결」을 누릅니다.

    블루투스 사용을 허용하고 목록에서 내 기기를 고릅니다.

V2 · V2E · V2X 전용입니다. 메뉴는 앱과 같고, 오토모드 · 홈 화면 위젯 · 시동 시 자동 연결만 안드로이드 앱에서 쓸 수 있습니다. 아이폰 웹 사용법
