설치 방법

처음 설치하기

쓰는 휴대폰 · PC 를 고르세요.

  1. 내 기기에 맞는 APK 를 받습니다.

    v1(배기밸브 · 안개등)은 N Controller Mobile, V2 · V2X · V2E 는 N Controller v2 입니다. 다운로드

  2. 받기를 물으면 「다운로드」를 누릅니다.

    브라우저가 「이 유형의 파일은 기기에 손상을 줄 수 있습니다」처럼 물으면 그래도 받기를 누릅니다.

  3. 받은 파일을 눌러 엽니다.

    「출처를 알 수 없는 앱」 설치를 막는 창이 뜨면 「설정」을 눌러 그 브라우저의 「이 출처 허용」(알 수 없는 앱 설치 허용)을 켜고 돌아옵니다.

  4. 「설치」를 누릅니다.

    Play 프로텍트 창이 뜨면 「세부정보 더보기」에서 「무시하고 설치」를 누릅니다.

  5. 앱을 열고 설명서대로 연결합니다.

    N Controller Mobile 설명서 · N Controller v2 설명서

새 앱 버전이 나오면 앱이 알려 줍니다. 앱을 지우지 말고 그 위에 설치해 주세요.

  1. PC 프로그램 ZIP 을 받습니다.

    v1(배기밸브 · 안개등) 전용입니다. 다운로드

  2. 압축을 풉니다.

    받은 ZIP 을 마우스 오른쪽 단추로 눌러 「압축 풀기」 · 「모두 압축 풀기」.

  3. N_Valve.controller.Update.exe 를 실행합니다.

    「Windows의 PC 보호」 창이 뜨면 「추가 정보」를 누른 뒤 「실행」을 누릅니다.

  4. 컨트롤러를 USB 로 연결합니다.

    처음 연결하는 기기는 신규 등록 창이 나타납니다. 닉네임을 넣고 등록을 마칩니다.

새 프로그램 버전이 나오면 프로그램이 알려 줍니다. 업데이트 중에는 USB 케이블을 분리하거나 PC 전원을 끄지 마세요. 자세한 것은 배기밸브 · 안개등 설명서를 보세요.

  1. App Store 에서 Bluefy 를 설치합니다.

    아이폰의 사파리 · 크롬은 웹에서 블루투스를 쓸 수 없어 블루투스를 쓰는 웹 브라우저가 필요합니다. 웹은 아이폰 전용입니다.

  2. Bluefy 에서 ncontroller.kr/app 을 엽니다.
  3. 시동을 걸고 「연결」을 누릅니다.

    블루투스 사용을 허용하고 목록에서 내 기기를 고릅니다.

V2 · V2X · V2E 전용입니다. 앱과 같은 메뉴를 쓰고, 오토모드 · 홈 화면 위젯 · 시동 시 자동 연결만 안드로이드 앱에 있습니다. 아이폰 웹 사용법
