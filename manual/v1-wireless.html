무선 연결 모듈 배선 안내

배기밸브 · 안개등 컨트롤러 무선 모듈

배선 색상에 맞춰 컨트롤러의 표시된 위치에 연결해 주세요.

1. 배선 연결표

배선 색상 연결 위치 확인 내용
빨간색 5V 전원 +
검은색 GND 전원 -
하얀색 D2 무선 신호 입력
노란색 D4 무선 신호 출력

2. 연결 전 확인

• 차량 시동과 컨트롤러 전원을 모두 꺼 주세요.

• USB 케이블을 분리한 상태에서 배선을 연결해 주세요.

• 5V와 GND를 반대로 연결하지 마세요.

• D2와 D4를 바꿔 연결하지 마세요.

3. 연결 방법

• 빨간색 배선은 5V 위치에 연결합니다.

• 검은색 배선은 GND 위치에 연결합니다.

• 하얀색 배선은 D2 위치에 연결합니다.

• 노란색 배선은 D4 위치에 연결합니다.

• 연결 후 배선이 빠지지 않도록 정리해 주세요.

4. 연결 후 확인

• 전원을 켜면 무선 연결 모듈의 LED가 깜빡입니다.

• 빠르게 깜빡이면 연결 대기 상태입니다.

• 느리게 깜빡이거나 고정되면 휴대폰과 연결된 상태입니다.

5. 앱 설정 순서

1. USB 케이블로 컨트롤러를 앱에 먼저 연결합니다.

2. 앱에서 컨트롤러 정보를 확인합니다.

3. 무선 연결 기기로 확인되면 무선 연결 설정을 진행합니다.

4. 앱 안내에 따라 무선 연결 이름과 비밀번호를 설정합니다.

5. 컨트롤러 전원을 껐다가 다시 켭니다.

6. 앱에서 블루투스 기기를 선택해 무선 등록을 완료합니다.

※ 무선 연결은 제어와 설정용입니다. 펌웨어 업데이트는 USB 연결이 필요합니다.
