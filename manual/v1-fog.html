N 안개등 컨트롤러 사용 설명서

안개등 컨트롤러 · PC 프로그램 · 차량 내 조작

중요 안내

차량 장착 전 PC 프로그램(또는 N Controller Mobile 앱의 USB 연결)으로 기기 등록과 최신 업데이트를 먼저 완료해 주세요. 펌웨어가 최신이 아니면 앱과 무선 연결을 사용할 수 없습니다. 등록 후 사용하면 업데이트와 점검 안내를 더 원활하게 받을 수 있습니다.

제 1 장. PC 프로그램 사용법

1. 프로그램 시작 및 기기 연결

  • 컨트롤러 케이스를 열고 내부 USB 포트에 케이블을 연결합니다.

  • N 밸브 컨트롤러 (PC) 프로그램을 실행한 뒤 USB 케이블로 컨트롤러와 PC를 연결합니다.

  • 정상 연결 시 프로그램이 안개등 컨트롤러를 자동으로 식별하고 현재 상태를 표시합니다.

  • 처음 연결하는 기기는 신규 등록 창이 나타납니다. 닉네임을 입력하고 등록을 완료해 주세요.

  • PC가 없으면 휴대폰의 N Controller Mobile 앱과 USB-C 데이터 케이블로도 기기 등록, 업데이트, 설정을 할 수 있습니다. (앱 사용 설명서 참고)

2. 업데이트

  • 업데이트가 필요한 경우 업데이트 버튼이 활성화됩니다.

  • 버튼을 누르면 최신 안개등용 프로그램을 자동으로 다운로드하여 설치합니다.

  • 업데이트는 USB 연결에서만 진행됩니다. 무선(블루투스) 연결로는 업데이트할 수 없습니다.

  • 업데이트 중에는 USB 케이블을 분리하지 마세요.

  • 업데이트가 실패하면 USB 연결, 인터넷 연결, 드라이버, 포트 사용 여부를 확인해 주세요.

3. 안개등 상세 설정

  • 상세 설정 화면에서 시동 모드, 모드 방식, 밝기, 점멸 패턴, 점멸 속도, 미등 연동, 검사 잠금을 설정할 수 있습니다.

  • 상단 프리뷰 이미지를 클릭하면 설정을 저장하기 전 화면에서 동작을 미리 볼 수 있습니다. 점멸모드 프리뷰는 선택한 패턴과 속도에 맞춰 빨간 LED처럼 점멸합니다.

  • 커스텀 패턴 제작 메뉴는 점멸 패턴을 커스텀 패턴으로, 커스텀 속도 메뉴는 점멸 속도를 커스텀으로 선택했을 때 표시됩니다.

  • 설정을 마친 뒤 설정 저장 후 닫기 버튼을 눌러야 기기에 적용됩니다.

설정 항목 설명
시동 모드 마지막 모드 / 순정/OFF / 상시켜짐 / 점멸모드 중 선택
모드 방식 3단 모드 또는 2단 모드 선택
3단 순서 순정/OFF → 상시켜짐 → 점멸모드 또는 순정/OFF → 점멸모드 → 상시켜짐
2단 조합 순정/OFF ↔︎ 상시켜짐 / 순정/OFF ↔︎ 점멸모드 / 상시켜짐 ↔︎ 점멸모드
통합 밝기 컨트롤러 표시 LED 밝기 50% / 75% / 100%. 안개등 자체 밝기는 바뀌지 않습니다.
미등 연동 켜면 미등이 켜졌을 때 표시 LED가 어두워집니다. 안개등 밝기와는 관계없습니다.
점멸 패턴 기본 점멸 / 3연속 점멸 / 커스텀 패턴
점멸 속도 느림 / 보통 / 빠름 / 커스텀 속도(0~100)
커스텀 패턴 PC 프로그램 또는 앱에서 켜짐/꺼짐 칸을 최대 16칸까지 직접 만듭니다.
검사 잠금 모드 켜기 / 끄기 (제 4 장 참고)

제 2 장. 차량 내 기본 조작법

1. 모드 변경

  • 버튼을 짧게 1회 누를 때마다 설정된 순서에 따라 모드가 바로 변경됩니다.

  • 3단 모드 기본값은 순정/OFF → 상시켜짐 → 점멸모드 → 순정/OFF 반복입니다. 2단 모드를 사용하면 선택한 두 모드만 서로 전환됩니다.

  • 버튼을 2초 이상 눌렀다 떼면 모드는 바뀌지 않습니다. 시동 직후 약 3초 동안은 버튼으로 모드를 바꿀 수 없습니다.

  • 2단 조합에 없는 모드를 시동 모드로 고르면 그 조합의 첫 모드로 시작합니다. 상시켜짐 ↔︎ 점멸모드 조합은 상시켜짐, 나머지 조합은 순정/OFF입니다.

모드 표시 동작
순정/OFF LED 꺼짐 안개등이 꺼진 상태
상시켜짐 빨간 LED 계속 켜짐 안개등이 계속 켜진 상태
점멸모드 빨간 LED가 안개등과 똑같이 깜빡임 선택한 패턴과 속도로 점멸

2. 점멸 패턴 설명

패턴 설명
기본 점멸 일정한 간격으로 켜짐/꺼짐을 반복합니다.
3연속 점멸 짧게 3회 점멸한 뒤 잠시 쉬는 패턴입니다.
커스텀 패턴 PC 프로그램 또는 앱에서 직접 만든 패턴(최대 16칸)으로 점멸합니다. 처음에는 3회 짧게 깜빡이고 쉬는 모양으로 들어 있습니다.

  • 커스텀 속도는 0~100 단계로 조절합니다. 0에 가까울수록 느리고, 100에 가까울수록 빠릅니다.

  • 점멸 속도를 커스텀으로 고르면 기본 점멸, 3연속 점멸, 커스텀 패턴 모두 커스텀 속도로 깜빡입니다. 커스텀 패턴도 느림 / 보통 / 빠름을 고를 수 있습니다.

제 3 장. 차량 내 수동 설정 메뉴

사용 안내

PC 연결이 어려운 상황에서 버튼만으로 주요 설정을 변경할 수 있습니다. 안개등 컨트롤러는 빨간 LED 하나로 메뉴 상태를 표시합니다.

  • 메뉴 진입: 버튼을 약 5초 이상 길게 누릅니다. 빨간 LED가 빠르게 5회 깜빡인 뒤 2회 더 깜빡이며 수동 설정 메뉴로 들어갑니다.

  • 다음 값 보기: 버튼을 짧게 누릅니다. 약 0.4초 뒤 값이 바뀌며, 마지막 값 다음에는 처음 값으로 돌아갑니다.

  • 현재 값 확정 후 다음 메뉴: 버튼을 2초 길게 누릅니다. LED가 잠깐 밝게 켜진 뒤 2회 깜빡이면 바로 손을 떼 주세요.

  • 빠르게 두 번 누르기: 지금 보이는 값 그대로 다음 메뉴로 넘어갑니다(2초 누르기와 같음).

  • 메뉴 안에서 버튼을 5초 이상 계속 누르고 있거나 30초 동안 입력이 없으면 저장하지 않고 메뉴를 나갑니다. 나갈 때 LED가 빠르게 5회 깜빡입니다.

  • 메뉴마다 빨간 LED로 현재 값을 보여 줍니다. M0 · M4는 깜빡이는 횟수, M1은 선택한 밝기(미등 연동 적용), M2 · M3는 실제 점멸 모양으로 표시합니다.

  • 메뉴는 항상 M0부터, 현재 저장된 값으로 시작합니다. 메뉴 안에 있는 동안에도 안개등은 현재 모드대로 계속 동작합니다.

  • 모드 방식, 커스텀 패턴 모양, 커스텀 속도 값은 버튼 메뉴로 바꿀 수 없으니 PC 프로그램이나 앱에서 바꿔 주세요.

순서 설정 항목 표시 및 옵션 비고
M0 시동 시 기본 모드 빨강 1회: 마지막 모드 / 2회: 순정/OFF / 3회: 상시켜짐 / 4회: 점멸모드 깜빡이는 횟수로 표시
M1 통합 밝기 50% / 75% / 100% 선택한 밝기로 점등 (표시 LED)
M2 점멸 패턴 기본 점멸 / 3연속 점멸 / 커스텀 패턴 실제 패턴으로 미리보기 / 커스텀 값은 PC·앱에서 제작
M3 점멸 속도 느림 / 보통 / 빠름 / 커스텀 실제 속도로 미리보기 / 커스텀 값은 PC·앱에서 설정
M4 미등 밝기 연동 빨강 1회: 켜짐 / 2회: 꺼짐 표시 LED 자동 밝기
SAVE 저장 및 종료 계속 켜짐: 저장 / 2회 반복 깜빡임: 취소 짧게 눌러 전환, 2초 길게 눌러 확정

제 4 장. 부가 기능

1. 검사 잠금 모드

  • 자동차 검사소 방문 등 안개등을 꺼진 상태로 고정해야 할 때 사용하는 기능입니다.

  • 버튼을 누른 채로 전원을 켜고 약 3초간 계속 누르고 있으면 기능이 켜지거나 해제됩니다. (전원이 들어오고 약 2초 뒤부터 1초 동안 버튼이 눌려 있어야 인식됩니다)

  • 켜지면 빨간 LED가 빠르게 5회, 해제되면 천천히 2회 깜빡입니다.

  • 앱 상세 설정(「시동 / 기본 동작」)의 「검사 잠금 모드」로도 켜고 끌 수 있습니다.

  • 기능이 켜지면 안개등과 표시 LED가 모두 꺼진 상태로 고정되고, 버튼 조작(모드 변경 · 설정 메뉴)과 앱의 모드 변경이 모두 막힙니다.

  • 설정은 시동을 껐다 켜도 유지되며, 해제하면 설정한 시동 모드로 동작합니다. 시동을 걸 때 버튼이 눌려 있으면 의도치 않게 켜지거나 꺼질 수 있습니다.

2. 자동 밝기 조절

  • 미등 연동이 켜져 있으면 차량 미등이 켜졌을 때 표시 LED가 자연스럽게 어두워집니다. 컨트롤러가 미등 신호에 맞춰 밝기 범위를 스스로 맞춥니다.

  • 표시 LED 밝기만 조절되며 안개등 밝기는 바뀌지 않습니다.

3. 시동 직후 보호 동작

  • 시동 직후 약 2초 동안은 안개등을 끈 상태로 유지한 뒤 설정한 시동 모드를 적용합니다.

  • 전압이 크게 떨어지거나 컨트롤러가 멈춰 스스로 다시 시작한 경우에는 안전을 위해 꺼진 상태로 시작합니다. 저장된 설정은 바뀌지 않으며 버튼으로 다시 켤 수 있습니다.

  • 이상이 반복되면 사용을 중지하고 고객센터에 문의해 주세요.

4. 버튼 보호

  • 버튼이 30초 넘게 눌린 채로 있으면(버튼 걸림 등) 그때부터 버튼 입력을 무시합니다. 설정 메뉴 중이었다면 저장하지 않고 닫습니다.

  • 모드는 그대로 유지되며, 버튼이 풀리면 정상으로 돌아옵니다.

5. 무선(블루투스) 연결

  • 무선 모듈이 설치된 컨트롤러는 N Controller Mobile 앱으로 모드 변경과 설정을 할 수 있습니다.

  • 무선 이름(3~20자)과 비밀번호(숫자 4자리) 등록은 USB로 연결한 상태에서 앱 안내에 따라 진행합니다. 자세한 내용은 앱 사용 설명서를 참고해 주세요.

  • PC 프로그램이나 앱이 USB로 컨트롤러와 통신하는 동안에는 무선으로 모드 변경, 설정 저장, 검사 잠금 변경을 할 수 없습니다. USB 연결을 끝내고 몇 초 뒤 다시 시도해 주세요.

  • 검사 잠금 중에는 앱으로도 모드를 바꿀 수 없습니다.

  • 펌웨어 업데이트는 무선으로 할 수 없으며, 반드시 USB로 연결해 진행해 주세요.

제 5 장. A/S 및 고객 지원

  • 기기 등록 고객은 제품 점검 및 업데이트 안내를 받을 수 있습니다.

  • 침수, 임의 개조, 배선 훼손, 과전압, 잘못된 장착으로 인한 고장은 유상 수리 대상이 될 수 있습니다.

  • 차량 판매, 중고 거래, 타인 양도 시 보증 조건이 변경될 수 있습니다.

  • 고객센터 문의는 PC 프로그램 또는 앱의 문의하기 버튼을 이용해 주세요. 앱의 문의하기는 카카오톡 상담으로 연결됩니다.

  • 주행 중에는 안전을 위해 설정 변경을 하지 말고, 정차 상태에서 조작해 주세요.
