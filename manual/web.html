아이폰 · 아이패드

아이폰의 사파리 · 크롬은 웹에서 블루투스를 쓸 수 없습니다. 블루투스를 쓰는 웹 브라우저 Bluefy 를 씁니다.

  1. App Store 에서 Bluefy 를 찾아 설치합니다.
  2. Bluefy 를 열고 주소 칸에 ncontroller.kr/app 을 넣습니다.
  3. 시동을 걸어 기기를 켠 뒤 연결을 누릅니다.
  4. 블루투스 사용을 물으면 허용하고, 목록에서 내 기기를 고릅니다.
  5. 블루투스 비밀번호를 정해 두었다면 6자리를 넣습니다.

Bluefy 에서 이 주소를 즐겨찾기에 넣어 두면 다음부터 바로 엽니다.

PC · 노트북

  1. 크롬 또는 엣지 최신 판을 씁니다.
  2. ncontroller.kr/app 을 엽니다.
  3. 연결을 눌러 목록에서 내 기기를 고릅니다.

웹에서 하는 것

  • 배기 모드 바꾸기 · 수동 % 조절
  • 펌웨어 업데이트
  • 안드로이드 앱과 같은 메뉴(기기에 맞는 것만 보입니다)

안드로이드 앱에만 있는 것

  • 오토모드(시간 · 장소 · 속도 · 터널)
  • 홈 화면 위젯
  • 시동 시 자동 연결

알아 두기

  • 기기는 한 번에 한 곳에만 연결됩니다. PC 나 다른 폰에서 웹을 열어 둔 채면 휴대폰 앱의 자동 연결이 붙지 않을 수 있습니다. 쓰지 않을 땐 웹 탭을 닫아 주세요.
  • 웹 화면을 닫거나 다른 앱으로 오래 나가 있으면 연결이 끊길 수 있습니다. 다시 열어 연결을 누르세요.
  • 연결할 때마다 서버에서 기기를 확인하므로 인터넷이 켜져 있어야 합니다.
  • 웹 조작도 반드시 정차 후 안전한 상태에서 해 주세요.

화면과 숫자는 예시이며, 앱 업데이트로 메뉴 이름이 조금 달라질 수 있습니다.
