아이폰 웹 사용법

아이폰에서 앱 설치 없이 V2 · V2E · V2X 쓰기 (Bluefy)

아이폰 전용

N Controller 웹은 아이폰 · 아이패드에서 앱 대신 쓰는 화면입니다. 아래 Bluefy로 열기를 누르면 바로 열립니다. 안드로이드 휴대폰은 「N Controller v2」 앱을 써 주세요.

쓸 수 있는 기기

  • V2 · V2E · V2X 컨트롤러
  • v1(배기밸브 · 안개등 컨트롤러)은 웹에서 쓰지 않습니다. 안드로이드 앱 「N Controller Mobile」 또는 PC 프로그램을 써 주세요.

처음 열기

아이폰의 사파리 · 크롬은 웹에서 블루투스를 쓸 수 없습니다. 블루투스를 쓰는 웹 브라우저 Bluefy 를 씁니다.

① Bluefy 받기 (App Store) ② Bluefy로 열기
  1. Bluefy 받기를 눌러 App Store에서 설치합니다.
  2. 이 페이지로 돌아와 Bluefy로 열기를 누릅니다. Bluefy가 열리며 N Controller 웹이 바로 뜹니다. (직접 넣으려면 Bluefy 주소 칸에 ncontroller.kr/app)
  3. 시동을 걸어 기기를 켠 뒤 연결을 누릅니다.
  4. 블루투스 사용을 물으면 허용하고, 목록에서 내 기기를 고릅니다.
  5. 처음 연결하면 기기 등록 창이 뜹니다. 차종과 기기 이름을 정합니다(V2E는 기기 이름만).
  6. 블루투스 비밀번호를 정해 두었다면 6자리를 넣습니다.

Bluefy에 이 주소를 즐겨찾기로 저장해 두면 다음부터 바로 열 수 있습니다. 두 번째부터는 「내 기기」 카드만 누르면 연결됩니다.

웹에서 할 수 있는 것

앱과 화면 · 메뉴가 같고, 내 기기에 맞는 메뉴만 보입니다. 메뉴마다 자세한 내용은 N Controller v2 앱 설명서와 같습니다.

계기판 방향

더보기 › 화면 › 계기판 › 방향에서 가로(기본) · 세로를 고릅니다. 아이폰은 웹 화면을 돌려 고정할 수 없어서, 고른 방향과 폰 방향이 다르면 계기판을 90° 돌려 그립니다. 폰을 그 방향으로 들면 바로 보입니다. 가로와 세로 배치는 따로 저장됩니다.

알아 두기

  • 기기는 한 번에 한 폰에만 연결됩니다. 다른 폰에서 웹이나 앱이 붙어 있으면 연결되지 않습니다.
  • 웹 화면을 닫거나 다른 앱으로 오래 나가 있으면 연결이 끊길 수 있습니다. 다시 열어 연결을 누르세요.
  • 연결할 때마다 서버에서 기기를 확인하므로 인터넷이 켜져 있어야 합니다.
  • 설정과 꾸민 계기판은 이 폰의 Bluefy에 저장됩니다. Bluefy를 지우면 계기판 배치가 지워집니다(기기 설정은 기기에 남습니다).
  • 웹 조작도 반드시 정차 후 안전한 상태에서 해 주세요.

화면과 숫자는 예시이며, 앱 업데이트로 메뉴 이름이 조금 달라질 수 있습니다.
