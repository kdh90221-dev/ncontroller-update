N Controller Mobile 앱 사용 설명서

배기밸브 · 안개등 컨트롤러 안드로이드 앱

가장 먼저 확인해 주세요

  • USB 연결과 펌웨어 업데이트는 차량 시동 / ACC 전원이 OFF인 상태에서 진행해 주세요.
  • USB 연결 중에는 차량 시동 / ACC 전원을 켜거나 끄지 마세요.
  • 충전 전용 케이블이 아닌 USB-C to USB-C 데이터 케이블을 사용해 주세요.
  • 펌웨어가 최신이 아니면 앱 사용과 무선 연결이 제한됩니다. 펌웨어 업데이트는 반드시 USB 연결로 진행해 주세요.
  • 무선 연결, 위젯, 시동 시 자동 연결, AUTO 모드는 무선 모듈이 설치된 컨트롤러 전용 기능입니다. AUTO 모드는 배기밸브 컨트롤러에서만 사용할 수 있습니다.
  • 무선 모듈이 없는 USB 전용 컨트롤러는 기존과 동일하게 USB 연결로 사용합니다.
  • 연결할 때마다 서버에서 기기를 확인하므로 휴대폰 인터넷(Wi-Fi 또는 모바일 데이터)이 켜져 있어야 합니다. 인터넷이 없으면 연결되지 않습니다.
  • 앱 조작은 반드시 정차 후 안전한 상태에서 진행해 주세요.

제 1 장. 앱 사용 준비 및 USB 연결

1. 준비물

  • Android 스마트폰 / N Controller Mobile 앱 / 인터넷 연결(연결할 때마다 기기를 확인합니다)

  • USB-C to USB-C 데이터 케이블 (충전 전용 케이블은 동작하지 않습니다)

  • N Controller 제품. 무선 기능을 쓰려면 무선 모듈이 설치된 컨트롤러가 필요합니다.

2. USB 연결 순서

  1. 차량 시동 / ACC 전원이 OFF인지 확인합니다.

  2. 스마트폰과 컨트롤러를 USB-C to USB-C 데이터 케이블로 연결합니다. 휴대폰이 「N Controller 앱을 열까요?」라고 물으면 확인을 누릅니다.

  3. 앱의 연결 화면에서 「연결」 묶음의 「USB 연결」을 누르고, 「USB 연결 안내」 창에서 확인을 누른 뒤 Android 권한 요청창에서 허용을 누릅니다.

  4. 기기 확인이 끝나면 홈 화면에 닉네임, 기기 종류, 펌웨어 상태, 현재 모드가 표시됩니다.

  • 케이블을 꽂기만 해서는 연결되지 않습니다. 앱에서 「USB 연결」을 눌러야 연결됩니다.

  • 무선으로 연결된 상태에서 USB로 연결하면 무선 연결은 자동으로 끊기고 USB 연결로 바뀝니다.

  • 케이블을 뽑으면 USB 연결이 끊기고 연결 화면으로 돌아갑니다.

  • USB 연결 중에는 위젯으로 제어할 수 없습니다.

제 2 장. 기기 등록 및 펌웨어 업데이트

1. 기기 등록

  1. 등록되지 않은 컨트롤러를 USB로 연결하면 「신규 기기 등록」 화면이 표시됩니다.

  2. 「닉네임」 칸에 사용할 이름을 입력하고 [등록 완료]를 누릅니다. 닉네임을 비워 두면 등록되지 않습니다.

  3. 등록이 끝나면 모드 변경, 설정 저장, 무선 등록 등 모든 기능을 사용할 수 있습니다.

  • 기기 등록은 USB 연결 상태에서만 진행됩니다. 등록 화면은 단계별로 진행되며, 화면 위쪽 점으로 현재 단계를 보여 줍니다.

  • 「기기 등록에 실패했습니다」가 표시되면 USB 연결을 확인한 뒤 다시 [등록 완료]를 눌러 주세요.

  • 「기기 등록을 위해 펌웨어 업데이트가 필요합니다」가 표시되면 [확인]을 눌러 업데이트를 먼저 진행합니다. 업데이트가 끝나면 등록 화면이 다시 표시됩니다. [취소]를 누르면 등록할 수 없습니다.

  • 「기기 정보에 문제가 있어 등록을 진행할 수 없습니다」 또는 「고객센터 확인 필요」가 표시되면 [문의하기]로 문의해 주세요.

2. 펌웨어 업데이트

  • 펌웨어가 최신이 아니면 앱 사용과 무선(블루투스) 연결이 제한됩니다. 이전 펌웨어를 사용 중이라면 반드시 USB로 연결해 먼저 업데이트해 주세요.

  • 구버전 컨트롤러를 USB로 연결하면 「펌웨어 업데이트」 창이 자동으로 표시됩니다. [확인]을 누르면 업데이트가 시작되고, [취소]를 누르면 다음으로 미룹니다.

  • 미룬 업데이트는 홈 「기기 상태」 카드의 펌웨어 칸이나 [펌웨어 업데이트] 버튼, 또는 디바이스 정보의 「펌웨어 업데이트」를 눌러 진행합니다.

  • 무선으로 연결된 상태에서 업데이트를 누르면 「펌웨어 업데이트는 USB 연결이 필요합니다」 안내가 표시됩니다. 「USB 연결하기」를 눌러 케이블로 연결해 주세요.

  • 업데이트 중에는 연결 화면에 「펌웨어 업데이트 중... N%」가 표시되고 뒤로 가기가 막힙니다. 끝나면 자동으로 다시 연결해 기기를 확인합니다.

  • 업데이트 중에는 차량 시동 / ACC 전원을 조작하지 말고 USB-C 케이블도 분리하지 마세요.

  • 케이블이 빠지거나 전원이 끊겨 업데이트가 끝나지 않았다면, 다시 USB로 연결하면 「업데이트 복구」 창이 표시됩니다. [복구 시작]을 눌러 주세요.

  • 위젯이나 자동 연결로 연결할 때 펌웨어 업데이트가 필요하면 「펌웨어 업데이트 필요」 알림으로 안내합니다.

3. 앱 업데이트

  • 새 앱 버전이 있으면 실행 시 「앱 업데이트 필요」 창이 표시됩니다. [업데이트]를 눌러 설치해 주세요. [종료]를 누르면 앱이 닫히며, 업데이트하기 전에는 앱을 사용할 수 없습니다.

  • 메뉴의 「앱 업데이트」에서 새 버전을 직접 확인할 수도 있습니다. 「최신」이면 그대로 사용하고, 「새 버전 있음」이 표시되면 눌러서 설치합니다.

  • 「설치 권한 필요」 창이 표시되면 [설정 열기]를 눌러 이 앱의 '알 수 없는 앱 설치'를 허용한 뒤 앱으로 돌아오면 이어서 진행됩니다.

  • 다운로드에 실패하면 「앱 업데이트 실패」 창에서 [다시 시도]를 누릅니다.

  • 위젯이나 자동 연결 중 앱 업데이트가 필요하면 「앱 업데이트 필요」 알림이 표시됩니다. 알림의 [업데이트]를 눌러 진행해 주세요.

제 3 장. 메인 화면 사용법

1. 연결 화면 (연결 전)

  • 「무선 컨트롤러 선택」에 무선 등록된 기기가 카드로 표시됩니다. 카드의 「무선 연결」을 누르면 바로 연결됩니다.

  • 「연결」 묶음에는 「USB 연결」, 「무선 등록 이어서 진행」, 「무선 연결 정보 업데이트 필요」, 「저장된 무선 등록 삭제」, 「메뉴」가 있습니다. 해당하는 경우에만 표시되는 항목도 있습니다.

  • 연결에 실패하면 연결 화면에 실패 내용이 표시됩니다(「무선 연결 실패」, 「위젯 연결 실패」, 「자동연결 실패」). [무선 연결]로 다시 시도하거나 [USB 연결] 또는 [닫기]를 누릅니다.

  • 「블루투스 권한 필요」 창이 표시되면 [권한 허용]을 누른 뒤 휴대폰 창에서 허용해 주세요. 「Bluetooth 꺼짐」 창이 표시되면 휴대폰 블루투스를 켜고 다시 시도해 주세요.

2. 홈 화면

  • 연결되면 아래쪽에 「홈 / 배기(안개등) / 더보기」 탭이 표시됩니다. 가운데 탭은 상세 설정(제 9 장)입니다.

  • 홈 맨 위에 연결 상태가 표시됩니다. USB는 「연결됨」, 무선은 「연결됨 · 무선 이름」, 확인 중에는 「확인 중」으로 표시됩니다. 새로고침(↻)을 누르면 기기 상태를 다시 읽어 옵니다.

  • 그 아래 상태판에 기기 이름, 현재 모드(큰 글자), 프리뷰 그림이 나옵니다. 기기 이름 줄을 누르면 디바이스 정보가 열립니다.

  • 프리뷰 그림을 누르면 실제 컨트롤러 모드가 바뀝니다. 컨트롤러 버튼을 누른 것과 같으며, 연속으로 누르지 말고 현재 모드가 다시 표시될 때까지 기다려 주세요.

  • 상태판 오른쪽 원에는 연결 방식(USB / 무선)이 표시됩니다. 무선 연결 중 위치·속도 AUTO나 터널 모드가 켜져 있으면 원에 GPS 속도가 나오고 기기 이름 옆에 [AUTO] 표시가 붙습니다. 터널 안에서는 「TUNNEL」, 속도를 알 수 없으면 「--」로 표시됩니다.

  • 원의 색은 GPS 상태입니다. 초록이면 양호, 노랑이면 보통, 빨강이면 신호가 약하거나 없는 상태입니다.

  • AUTO로 모드가 바뀌었으면 모드 아래에 바뀐 시각과 이유(예: 속도 AUTO)가 표시됩니다.

  • 「기기 상태」 카드에는 펌웨어(최신 버전 / 업데이트 필요 / USB 필요 / 확인 필요), 검사 잠금(켜짐 / 꺼짐), 시동 모드가 나옵니다. 펌웨어 업데이트가 필요하면 카드가 주황색으로 바뀌고, USB로 연결된 상태면 [펌웨어 업데이트] 버튼이 나옵니다. 카드를 누르면 디바이스 정보가 열립니다.

  • 무선으로 연결하면 「최근 자동 전환」 카드에 AUTO가 모드를 바꾼 최근 2건이 나오며, 「전체」를 누르면 운행 기록이 열립니다. 기록이 아직 없으면 켜 둔 「AUTO 모드」 목록이, AUTO가 하나도 없으면 「등록된 AUTO 모드가 없습니다」와 [설정]이 나옵니다.

  • 위치·속도 AUTO나 터널 모드가 켜져 있고 운행 기록이 있으면 「최근 운행」 카드에 경로 그림, 거리, 시간, 자동 전환 횟수가 표시됩니다. 누르면 운행 기록이 열립니다.

  • USB로 연결하면 「무선 연결」 카드가 나옵니다. 무선 등록된 기기는 무선 이름과 「등록됨」, [무선 재등록], 「시동 시 자동 연결」 사용 여부, 「홈 화면 위젯」 개수가 표시되고, 무선 모듈은 있지만 아직 등록 전이면 [무선 연결 등록]이 나옵니다. 무선 모듈이 없는 기기는 표시되지 않습니다.

  • 「사용 시간」 카드에서 현재 운행(연결 전에는 최근 운행), 트립 기록, 누적 사용 시간을 확인할 수 있습니다.

  • 휴대폰 화면 한 장에 다 들어가지 않으면 덜 중요한 카드부터 숨겨집니다.

  • 트립 기록 초기화: 「트립 기록을 초기화하시겠습니까?」에서 [초기화]를 누릅니다.

  • 무선으로 연결된 상태에서 메뉴 또는 AUTO 모드 탭의 「운행 기록」을 누르면 지도에 주행 경로와 AUTO · 터널 모드가 동작한 지점이 표시됩니다. 운행 기록은 휴대폰의 위치 정보를 사용합니다.

  • 지도 버튼: [+] / [-] 확대·축소, ◉ 내 위치 따라가기, 🧭 진행 방향 고정, 🔍 자동 확대, [X] 닫기.

  • 「기록 보기」를 누르면 날짜 선택, [전체 날짜], [기록 삭제]가 나오고 속도 · 위치 · 시간 · 터널 · 조작 표시를 켜고 끌 수 있습니다.

  • 아래 칸을 누르면 운행 목록이 펼쳐지고, 운행을 누르면 지도에 그 운행이 표시됩니다.

  • 삭제는 「선택 운행기록 삭제」 / 「(날짜) 기록 삭제」 / 「전체 기록 삭제」 중에서 고릅니다.

  • 지도 위쪽의 모드 표시를 누르면 컨트롤러 모드가 실제로 바뀌니 주의해 주세요.

6. 알림, 연결 끊기, 앱 종료

  • 무선으로 연결되면 알림에 「N 컨트롤러 · 연결됨」과 현재 모드가 표시됩니다. AUTO나 터널 모드가 동작 중이면 함께 표시됩니다. 연결이 끊겨 다시 잇는 중이면 「다시 연결하는 중」이 표시됩니다.

  • USB로 연결하면 「USB 연결됨」이, 업데이트 중에는 진행률과 「선을 뽑지 마세요」가 표시됩니다.

  • 그 밖에 「연결하는 중 · 시동 시 자동 연결」, 「펌웨어 업데이트 필요」, 「앱 업데이트 필요」, 「AUTO 설정이 필요합니다」 알림이 있습니다. 알림을 누르면 앱이 열립니다.

  • 다른 N 컨트롤러 앱을 함께 쓰는 경우 알림 제목이 「배기 컨트롤러」 또는 「안개등 컨트롤러」로 표시되어 구분됩니다.

  • 무선 연결을 끊으려면 알림의 [연결 끊기]를 누르거나, 최근 앱 화면에서 앱을 밀어 닫거나, 홈 화면에서 뒤로 가기를 눌러 「앱을 종료하시겠습니까?」에서 [확인]을 누릅니다.

  • 상세 설정이나 더보기 화면에서 뒤로 가기를 누르면 홈으로 돌아옵니다.

  • 무선으로 사용 중 연결이 끊긴 경우에는 앱으로 돌아오거나 화면 잠금을 해제하면 다시 연결합니다. 직접 연결을 끊은 뒤에는 다시 연결하지 않습니다.

  • 알림 권한은 AUTO 모드를 설정할 때 요청합니다. AUTO를 쓰지 않는다면 휴대폰 설정 › 애플리케이션 › N Controller › 알림에서 허용해 주세요.

제 4 장. 무선(블루투스) 등록 및 연결

1. 무선 등록 전체 순서

처음 한 번만 등록하면, 이후에는 연결 화면의 기기 카드에서 「무선 연결」만 눌러 바로 연결됩니다.

  1. USB로 컨트롤러를 연결하고 기기 확인·기기 등록을 먼저 완료합니다.

  2. 「무선 연결」 창이 표시되면 [설정하기]를 누릅니다. 나중에 하려면 [나중에 하기]를 누르고, 메뉴의 「현재 컨트롤러 무선 등록/재등록」으로 다시 시작할 수 있습니다.

  3. 「무선 연결 설정」 화면에서 무선 이름과 연결 비밀번호(숫자 4자리)를 확인하거나 입력하고 저장합니다.

  4. 「1단계 완료」 창에 표시된 기기 이름과 비밀번호를 확인하고 [다음]을 누릅니다. USB 케이블은 뽑지 마세요.

  5. 블루투스 검색 목록에서 내 컨트롤러를 선택합니다.

  6. 휴대폰에 페어링 요청이 뜨면 앞에서 정한 비밀번호를 입력합니다.

  7. 페어링이 끝나면 등록과 무선 연결까지 자동으로 진행됩니다.

  • 이미 이름·비밀번호를 설정한 컨트롤러를 다른 휴대폰에 등록할 때는 「무선 연결 등록」 창에서 [등록]을 누르면 바로 블루투스 검색으로 넘어갑니다.

등록 중에는 이렇게 해 주세요

  • 이름·비밀번호를 저장하는 동안 휴대폰이 컨트롤러와 블루투스로 연결되어 있으면 저장이 실패합니다. 이미 연결되어 있다면 휴대폰 블루투스 설정에서 연결을 끊고 진행해 주세요. (실패 창에서 [다시 시도] 가능)
  • 등록이 끝날 때까지 USB 케이블을 뽑지 않는 것이 가장 빠릅니다.
  • 도중에 USB가 빠지거나 앱이 닫혀도 등록 정보는 남습니다. 앱을 다시 열면 「무선 등록이 끝나지 않았습니다」 안내가 뜨고, [이어서 등록]을 누르면 USB 없이 남은 과정을 끝낼 수 있습니다.

2. 무선 이름과 비밀번호

  • 처음에는 기본 이름(배기 NCTRL_E_□□□□, 안개등 NCTRL_F_□□□□)과 기본 비밀번호(기기번호 끝 4자리)가 들어 있습니다. 그대로 사용해도 됩니다.

  • 무선 이름은 영문·숫자 3~20자이며 밑줄(_)과 하이픈(-)도 쓸 수 있습니다. 한글은 사용할 수 없습니다. 연결 비밀번호는 숫자 4자리이며, 페어링할 때 휴대폰에 입력하는 번호입니다.

  • 이름과 비밀번호는 안내창에 함께 표시되므로 따로 적어 두지 않아도 됩니다.

  • 배기밸브와 안개등을 모두 사용하는 경우, 기기마다 다른 이름을 지정하면 구분하기 쉽습니다.

3. 블루투스 검색 화면

  • 검색 목록에는 등록하려는 컨트롤러만 표시됩니다. 보이지 않으면 [다시 검색]을 눌러 주세요.

  • 그래도 안 보이면 [찾는 기기가 안 보여요]로 주변 기기를 모두 표시할 수 있습니다. 버튼이 「내 컨트롤러만 보기」로 바뀌며, 다시 누르면 원래 목록으로 돌아옵니다. 잘못 선택해도 앱이 기기를 확인해 다른 기기면 등록되지 않으므로 안전합니다.

  • 컨트롤러에 전원이 들어와 있어야 검색됩니다. 계속 안 보이면 컨트롤러 전원을 껐다 켠 뒤 다시 검색해 주세요.

  • [블루투스 설정] 버튼으로 휴대폰의 블루투스 설정 화면을 바로 열 수 있고, [무선 재등록] 버튼으로 이름·비밀번호를 다시 정할 수 있습니다.

4. 무선 연결과 기기 바꿔 쓰기

  • 연결 화면의 「무선 컨트롤러 선택」에서 원하는 기기 카드의 「무선 연결」을 누릅니다.

  • 무선 연결은 한 번에 한 대만 됩니다. 다른 기기로 바꾸려면 알림의 [연결 끊기]로 끊은 뒤 다른 기기 카드의 「무선 연결」을 누릅니다.

  • 다른 기기의 위젯을 누르면 연결이 그 기기로 바뀌고 모드도 함께 바뀝니다.

5. 재등록 · 이어서 진행 · 삭제

  • 무선 재등록: 더보기 > 메뉴 > 「무선 재등록」에서 이름·비밀번호를 바꿉니다. USB 연결 상태에서만 진행됩니다. 이름을 바꾼 경우 휴대폰에 남은 기존 페어링을 삭제한 뒤 다시 등록하는 것이 좋습니다.

  • 이어서 진행: 「무선 등록이 끝나지 않았습니다」 창에서 [이어서 등록] / [나중에 하기] / [등록 취소]를 고릅니다. [등록 취소]는 남은 등록 정보를 지웁니다. 연결 화면의 「무선 등록 이어서 진행」으로도 이어서 할 수 있습니다.

  • 「무선 연결 정보 업데이트 필요」가 표시되면 예전 방식으로 저장된 등록입니다. USB로 컨트롤러를 연결한 뒤 무선 연결 설정을 다시 진행해 주세요.

  • 삭제: 연결 화면 「연결」 묶음의 「저장된 무선 등록 삭제」를 누르면 기기 목록과 「전체 삭제」가 나옵니다. 누르는 즉시 삭제되며, 삭제 후에는 USB로 처음부터 다시 등록해야 합니다.

제 5 장. 홈화면 위젯

  • 앱을 열지 않고 홈화면에서 컨트롤러 상태를 확인하고 모드를 전환할 수 있습니다.

  • 작은 위젯과 넓은 위젯이 있으며, 크기를 조절하면 표시 요소가 맞춰집니다.

  • 위젯은 무선 등록이 완료된 컨트롤러에서만 사용할 수 있습니다.

1. 위젯 추가 방법

  1. 무선 등록이 완료된 컨트롤러를 준비합니다.

  2. 앱의 더보기 > 메뉴 > 「위젯 추가」를 누르거나, 휴대폰 홈화면을 길게 눌러 위젯 목록에서 N Controller 위젯을 선택합니다.

  3. 위젯 설정 화면에서 「컨트롤러 선택」, 「위젯 테마」, 「배경 투명도」(0~100%)를 고르고 「미리보기」로 확인한 뒤 [위젯 추가]를 누릅니다.

  • 앱의 「위젯 추가」로 붙이는 위젯은 넓은 위젯입니다. 작은 위젯은 홈화면의 위젯 목록에서 추가해 주세요.

  • 홈화면에 바로 붙이기를 지원하지 않는 휴대폰은 홈화면을 길게 눌러 직접 추가해 주세요.

  • 위젯 테마는 퍼포먼스 · 레드 · 오렌지 · 블루 · 그레이 · 커스텀 중에서 고릅니다. 커스텀을 고르면 「배경」, 「글자」, 「글자 박스」, 「엠비언트」 색을 R·G·B로 정합니다.

  • 무선 등록된 기기가 없으면 「무선 프로필 없음」이 표시되고 위젯을 추가할 수 없습니다.

  • 이미 붙인 위젯의 테마나 컨트롤러를 바꾸려면 위젯을 지우고 다시 추가해 주세요.

2. 위젯 표시

표시 의미
NORMAL / CLOSE / OPEN 배기 현재 모드 (순정 / 닫힘 / 열림)
OFF / ON / FLASH 안개등 현재 모드 (순정·OFF / 상시켜짐 / 점멸모드)
CONN 연결 필요
WAIT 모드 바꾸는 중
SYNC 연결 · 상태 확인 중
LOCK 검사잠금 중 (위젯으로 모드 변경 불가)
TUNNEL 터널 모드 동작 중
MANNER 매너모드

  • 넓은 위젯에는 「N EXHAUST」 / 「N FOG」, 「● BT」(파랑 = 연결됨, 회색 = 연결 안 됨), [AUTO]·[MANNER] 표시가 함께 나옵니다.

3. 위젯 누르기

  • 연결된 상태에서 위젯을 누르면 모드가 바뀝니다.

  • CONN · SYNC · LOCK일 때 누르면 연결만 하고 모드는 바꾸지 않습니다. 연결된 뒤 다시 누르면 모드가 바뀝니다.

  • 다른 기기에 연결 중이라 흐리게 보이는 위젯을 누르면 그 기기로 연결을 바꾸고 모드도 함께 바꿉니다.

  • 위젯으로 연결하면 앱을 띄우지 않고 뒤에서 연결되며, 나중에 앱을 열면 그 연결을 그대로 이어서 사용합니다.

  • 위젯 연결에 실패하면 앱이 열리고 「위젯 연결 실패」 화면이 표시됩니다.

4. 사용 시 주의사항

  • 휴대폰 블루투스와 컨트롤러 전원이 켜져 있어야 합니다.

  • 모드를 변경한 뒤 실제 상태가 반영될 때까지 잠시 기다려 주세요.

  • USB 연결 중에는 위젯으로 제어할 수 없습니다.

  • 기기 등록과 펌웨어 업데이트는 위젯이 아닌 앱의 USB 연결에서 진행합니다.

제 6 장. 시동 시 자동 연결

시동을 걸어 휴대폰이 차량 블루투스에 연결되면, 앱을 열거나 위젯을 누르지 않아도 컨트롤러가 자동으로 무선 연결되는 기능입니다. 앱 설정만으로 사용할 수 있으며, 갤럭시 이외의 휴대폰에서도 사용할 수 있습니다.

먼저 준비해 주세요

  • 무선 등록이 완료된 컨트롤러가 있어야 합니다. (제 4 장 참고)
  • 차량 블루투스(순정 오디오·핸즈프리)와 휴대폰이 이미 페어링되어 있어야 합니다.
  • 무선 모듈이 설치된 기기에서만 메뉴에 표시됩니다.

1. 설정 순서

  1. 더보기 > 메뉴 > 「자동 연결」 묶음의 「시동 시 자동 연결」을 누릅니다. (연결 전에는 연결 화면의 「메뉴」에서 열 수 있습니다)

  2. 「시동만 걸면 바로 연결돼요」 안내 화면에서 [내 차 고르기]를 누르고, 목록에서 차 블루투스(차 오디오나 내비 이름)를 선택합니다.

  3. 휴대폰이 연결 허용 여부를 물어보면 「허용」을 누릅니다.

  4. 「배터리 설정」 창에서 [설정 열기]를 눌러 이 앱의 배터리 사용을 「제한 없음」으로 바꿉니다. ([나중에]도 가능하지만 연결이 늦거나 안 될 수 있습니다)

  5. 「시동 시 자동 연결을 켰어요」가 표시되면 완료입니다. 다음 시동부터 자동으로 연결됩니다.

화면 항목 설명
사용 상태 「● 사용 중 · 마지막 연결 시각」 또는 「● 꺼짐」 표시
켜기 / 끄기 스위치 자동 연결을 잠시 끄거나 다시 켜기
다른 차로 바꾸기 자동 연결할 차 블루투스 변경
자동 연결 끄기 확인 창에서 [끄기]를 누르면 해제 (다시 쓰려면 내 차를 다시 선택)

2. 동작 방식과 참고 사항

  • 시동을 걸어 휴대폰이 차 블루투스에 연결되면 알림에 「연결하는 중 · 시동 시 자동 연결」이 표시되고 컨트롤러에 연결합니다.

  • 홈화면에 위젯을 추가한 컨트롤러가 있으면 그 컨트롤러에 연결합니다. 위젯이 없으면 「내 차」를 고를 때 연결돼 있던 컨트롤러(없으면 처음 등록한 컨트롤러)에 연결합니다.

  • 연결에 실패하면 한 번 더 시도하고, 그래도 안 되면 알림을 없애고 끝냅니다. 위젯에는 CONN이 표시되며 위젯을 눌러 다시 연결할 수 있습니다.

  • 차 블루투스가 다시 연결되면 자동 연결을 다시 시도합니다.

  • 운행 중 직접 연결을 끊으면 그 운행 동안에는 다시 자동 연결하지 않습니다. 시동을 껐다 다시 걸면 정상 동작합니다.

  • 「자동 연결 시 앱 열기」를 켜 두면 자동으로 연결될 때 앱도 함께 열립니다.

자동 연결이 실행되지 않을 때

  • 휴대폰 설정 > 애플리케이션 > N Controller 에서 배터리 항목이 '제한 없음'인지 확인해 주세요.
  • 삼성 휴대폰은 이 앱이 「절전 앱」이나 「딥 슬립 앱」에 들어가면 연결되지 않습니다. 설정 › 배터리 › 백그라운드 사용 제한에서 확인해 주세요.
  • 「컨트롤러 말고 차 블루투스를 골라 주세요」가 뜨면 컨트롤러가 아닌 차 오디오나 내비 이름을 선택해 주세요.
  • 「휴대폰에서 허용하지 않아 시동 시 자동 연결을 켜지 못했어요」가 뜨면 다시 골라 「허용」을 눌러 주세요.
  • 「연결한 적 있는 차 블루투스가 없어요」가 뜨면 휴대폰을 차 블루투스에 먼저 한 번 연결해 주세요.

제 7 장. AUTO 모드 (자동 전환)

정해 둔 조건이 되면 컨트롤러 모드를 자동으로 바꿔 주는 기능입니다. 무선으로 연결된 배기밸브 컨트롤러에서 사용할 수 있습니다. (안개등 컨트롤러는 지원하지 않습니다)

종류 동작
시간 AUTO 지정한 요일과 시각이 되면 모드를 바꿉니다.
위치 AUTO 지도에서 지정한 위치(반경)에 들어오거나 벗어나면 모드를 바꿉니다.
속도 AUTO 기준 속도보다 빨라지거나 느려지면 모드를 바꿉니다.
주행상태 AUTO 정지 · 주행 · 고속 상태에 따라 모드를 바꿉니다.
급가속 AUTO 급가속을 감지하면 지정한 모드로 바꾸고, 유지 시간이 지나면 원래 모드로 돌아갑니다.
터널 모드 터널에 진입하면 모드를 바꾸고, 빠져나오면 원래 모드로 되돌립니다.

1. 처음 준비 (권한과 지도 데이터)

  1. 「위치(속도) AUTO에 위치 권한이 필요합니다」 창에서 [계속]을 누르고 휴대폰 창에서 위치 권한을 허용합니다.

  2. 「백그라운드 위치 권한」 창에서 [설정 열기]를 눌러 위치 권한을 '항상 허용'으로 바꿉니다.

  3. 알림 권한을 허용합니다.

  4. 「배터리 제한 해제 권장」 창에서 [설정 열기]를 눌러 배터리 제한을 해제합니다.

  5. 「지도 데이터 필요」 창에서 [다운로드]를 눌러 지도 데이터(약 60MB)를 받습니다. Wi-Fi 연결을 권장합니다.

  • '대략적 위치'만 허용하면 「정확한 위치 필요」 창이 뜹니다. 휴대폰 설정 › 권한 › 위치에서 「정확한 위치 사용」을 켜 주세요.

  • 예전에 권한을 거절해 다시 묻지 않는 상태라면 「권한 필요」 창에서 [설정 열기]로 직접 허용해 주세요.

  • 지도 데이터를 받는 동안 「지도 데이터 받는 중」과 진행률이 표시되며 [취소]할 수 있습니다. 한 번 받으면 주행 중에는 통신하지 않습니다.

  • 지도 데이터를 받지 않으면 AUTO 모드와 터널 모드가 동작하지 않습니다. 새 도로·터널이 반영된 데이터가 나오면 「새 지도 데이터」 창에서 [다운로드] / [나중에]를 고릅니다.

2. AUTO 모드 추가

  1. 무선으로 배기밸브 컨트롤러에 연결한 뒤 아래쪽 「배기」 탭을 누르고 「AUTO 모드」 탭을 엽니다.

  2. [+ AUTO 모드 추가]를 누르고 「언제 실행할까요?」에서 시간 / 위치 / 속도 중 하나를 고릅니다.

  3. 조건과 바꿀 모드를 입력하고 [다음]을 누르면 「AUTO 모드 확인」 창에 이름 · 조건 · 실행 · 조건 해제가 표시됩니다. [저장]을 누르면 목록에 추가됩니다.

  4. 마지막으로 「설정 저장」을 눌러야 컨트롤러에 적용됩니다.

종류 입력 항목
시간 AUTO 요일(월~일, 처음에는 전체 선택) / 시(0~23)·분(0~59, 24시간 기준) / 실행 모드(순정·닫힘·열림)
위치 AUTO 지도를 눌러 위치 선택 또는 [현재위치] / 반경 [−]·[+] 50m 단위(50~1000m, 기본 150m) / [이 위치와 반경으로 설정] / 실행 조건 [진입]·[이탈] / 실행 모드
속도 AUTO 방식: 속도 AUTO / 기준 속도(30~200km/h, 5 단위) / 실행 시점(기준보다 빠를 때·느릴 때) / 현재 모드 조건(사용 안 함 또는 순정·닫힘·열림일 때만) / 조건이 맞으면 바꿀 모드 / 조건이 해제되면(지정한 모드로 변경·그대로 유지)
주행상태 AUTO 방식: 주행상태 AUTO / 정지 중 모드(사용 안 함 가능) / 주행 중 모드 / 고속 기준 속도 / 고속 주행 중 모드(사용 안 함 가능). 정지와 고속 중 하나는 꼭 지정
급가속 AUTO 방식: 급가속 AUTO / 급가속 감도: 민감·보통·둔감(1초에 7·10·15km/h 이상 빨라질 때) 또는 직접 설정(3~100km/h) / 급가속 시 모드 / 유지 시간 3·5·8·10·15초 후 원래 모드

3. AUTO 목록 관리

  • 목록 카드마다 조건 · 실행 · 해제 시 동작이 표시됩니다. 스위치로 켜고 끄며, [삭제]로 지웁니다.

  • 등록한 AUTO를 고치는 기능은 없습니다. 삭제한 뒤 다시 추가해 주세요.

  • 속도 조건(속도 / 주행상태 / 급가속)은 하나만 사용할 수 있습니다. 하나 더 추가하면 「속도 조건은 하나만 사용할 수 있습니다」가 뜨며, [기존 항목 수정]을 누르면 기존 항목이 방금 입력한 값으로 바뀝니다.

  • 실행 모드와 해제 모드가 같으면 저장되지 않습니다.

  • 속도 AUTO에 현재 모드 조건을 넣으면 목록에 「모드 보호 AUTO」로 표시되며, 지정한 모드일 때만 동작하고 조건이 풀려도 바뀐 모드를 그대로 유지합니다.

4. 터널 모드

  1. AUTO 모드 탭의 「터널 모드」 줄을 누릅니다.

  2. 「터널로 판단되면 실행할 모드」(사용 안 함 / 순정 / 닫힘 / 열림)와 「적용할 터널 종류」(전체 터널 / 고속도로 터널 / 자동차 전용+고속도로 터널)를 고릅니다.

  3. [확인]을 누르면 「터널 모드」 안내가 뜹니다. [계속]을 눌러야 켜지며, 「설정 저장」을 눌러 적용합니다.

  • 터널을 빠져나오면 원래 모드로 되돌립니다. 터널 모드는 보조 기능이므로 GPS 상태에 따라 늦거나 놓칠 수 있습니다.

AUTO 모드는 휴대폰 권한이 필요합니다

  • 위치 · 속도 · 터널 조건은 휴대폰의 위치 정보를 사용합니다. 위치 권한을 요청하면 허용해 주세요.
  • 화면이 꺼져 있어도 동작하려면 위치 권한을 '항상 허용'으로 설정해야 합니다.
  • 절전 기능이 켜져 있으면 위치 확인 간격이 늘어나 터널·속도 조건이 늦게 동작하거나 놓칠 수 있습니다. 배터리 제한 해제 안내가 뜨면 허용해 주세요.
  • 알림 권한을 허용하면 AUTO 동작 상태를 알림에서 확인할 수 있습니다. 권한이 모자라면 「AUTO 설정이 필요합니다」 알림이 뜨며, 누르면 이어서 설정할 수 있습니다.

5. 사용 시 참고

  • AUTO 모드가 동작하려면 휴대폰과 컨트롤러가 무선으로 연결되어 있어야 합니다.

  • AUTO로 모드가 바뀐 뒤 직접 모드를 바꾸면 사용자가 바꾼 모드가 우선 적용됩니다.

  • 조건이 서로 겹칠 수 있으므로, 처음에는 한두 가지만 켜고 동작을 확인한 뒤 늘려 가시길 권장합니다.

  • AUTO 모드 탭이나 메뉴의 「운행 기록」에서 AUTO가 동작한 기록을 지도로 확인할 수 있습니다.

  • AUTO 모드는 주행 편의를 위한 보조 기능입니다. 주행 중 앱 조작은 하지 마세요.

제 8 장. 앱 테마 및 화면 설정

  • 메뉴의 「앱 테마」에서 테마를 선택합니다. 퍼포먼스 테마는 전용 배경과 강조 색상이 적용됩니다.

  • 「커스텀」을 고르면 「커스텀 앱 테마」 창이 열립니다. 배경 · 박스 · 글자를 정한 뒤 창 아래 [적용]을 눌러야 테마가 바뀝니다.

  • 테마는 앱 배경과 카드 색상만 바꿉니다. 모드 색상과 경고 색상은 안전 구분을 위해 그대로 유지되며, 컨트롤러 동작과는 관계가 없습니다.

제 9 장. 상세 설정

  • 상세 설정은 연결 후 아래쪽 「배기」 또는 「안개등」 탭에서 엽니다.

  • 바꾼 값은 위쪽 프리뷰와 모드 표시에 저장 전에 바로 반영되어 미리 확인할 수 있습니다.

  • 바꾼 뒤 「설정 저장」을 누르지 않고 홈 · 더보기 탭이나 뒤로 가기로 나가면 바꾼 내용(AUTO 포함)이 취소됩니다.

  • 검사잠금이 켜져 있으면 잠금 설정만 표시됩니다.

  • 스위치를 누르면 「검사잠금 설정」 또는 「검사잠금 해제」 확인 창이 뜹니다. [설정] / [해제] 또는 [취소]를 누릅니다.

  • 잠금 중에는 프리뷰를 눌러도 모드가 바뀌지 않습니다. 컨트롤러 버튼으로 켜고 끄는 방법은 각 컨트롤러 설명서를 참고해 주세요.

검사잠금 모드는 점검 또는 검사 상황을 위한 기능입니다. 일반 주행 전에는 현재 상태를 확인하고, 필요한 경우 해지한 뒤 사용해 주세요.

제 10 장. 설정 저장 및 커스텀 패턴

1. 설정 저장

  • 설정을 바꾼 뒤 「설정 저장」을 누르면 「설정 저장 확인」 창에 「시동 모드(마지막 모드→순정)」처럼 바뀐 내용이 표시됩니다. [저장]을 누르면 저장되고 「설정 저장이 완료되었습니다」가 표시됩니다.

  • 바뀐 내용이 없으면 「변경사항이 없습니다. 그래도 현재 설정을 다시 저장할까요?」가 표시됩니다.

  • AUTO 규칙과 터널 모드 설정도 「설정 저장」을 눌러야 적용됩니다.

  • 무선 연결 상태에서도 설정을 저장할 수 있습니다. 펌웨어 업데이트만 USB에서 진행됩니다.

  • USB로 연결해 저장할 때는 차량 시동 / ACC 전원을 OFF로 유지하고 USB-C 케이블을 분리하지 마세요.

2. 커스텀 패턴

  • 「패턴 길이」 막대로 1~16칸을 정한 뒤, 아래 칸을 하나씩 눌러 ON(켜짐) / OFF(꺼짐)를 바꿉니다. 「-」 칸은 사용하지 않는 칸입니다.

  • 패턴 길이와 점멸 속도에 따라 실제 점멸 느낌이 달라집니다.

  • 배기밸브는 닫힘 / 열림 모드에 각각, 안개등은 점멸모드에 커스텀 패턴을 설정할 수 있습니다.

제 11 장. 문제 해결

1. USB 연결이 안 될 때

  • USB-C to USB-C 케이블이 데이터 전송용인지 확인해 주세요. 충전 전용 케이블은 인식되지 않습니다.

  • USB를 연결할 때 차량 시동 / ACC 전원이 OFF인지, Android 권한창에서 허용을 눌렀는지 확인해 주세요.

  • 케이블을 다시 꽂고 연결 화면의 「USB 연결」을 다시 눌러 주세요.

  • 「기기 응답을 확인하지 못했습니다」가 표시되면 USB를 뽑았다가 다시 연결해 주세요.

3. 무선 연결 · 위젯 · 자동 연결이 안 될 때

  • 무선 모듈이 설치된 컨트롤러인지, 휴대폰 블루투스가 켜져 있는지 확인해 주세요.

  • 「무선 연결 실패」가 표시되면 컨트롤러 전원과 휴대폰 블루투스를 확인한 뒤 [무선 연결]로 다시 시도해 주세요.

  • 「저장된 무선 등록 정보와 현재 컨트롤러가 일치하지 않습니다」가 표시되면 해당 컨트롤러의 전원을 확인한 뒤 다시 연결해 주세요.

  • 「무선 연결 확인 필요」가 표시되면 USB로 연결해 기기 상태를 확인해 주세요.

  • 무선 등록이 끝났는지 확인해 주세요. 등록이 남아 있으면 연결 화면의 「무선 등록 이어서 진행」에서 이어서 진행할 수 있습니다.

  • 다른 휴대폰이 같은 컨트롤러에 연결되어 있으면 새로 연결되지 않습니다.

  • 시동 시 자동 연결이 실행되지 않으면 휴대폰 설정에서 이 앱의 배터리 항목을 '제한 없음'으로 바꿔 주세요. 삼성 휴대폰은 「절전 앱」·「딥 슬립 앱」에 들어가 있지 않은지도 확인해 주세요.

  • 펌웨어가 최신이 아니면 무선 연결이 되지 않을 수 있습니다. USB로 연결해 펌웨어를 먼저 업데이트해 주세요.

  • 「서버 확인에 실패했습니다」가 표시되면 휴대폰 인터넷(Wi-Fi 또는 모바일 데이터)을 켠 뒤 다시 연결해 주세요. 인터넷이 없으면 연결되지 않습니다.

  • 「컨트롤러 응답을 받지 못했습니다」가 표시되면 잠시 후 다시 연결해 주세요. 계속되면 컨트롤러 전원을 껐다 켜 주세요.

  • 연결이 계속 끊기면 컨트롤러 전원을 껐다 켠 뒤 다시 연결해 주세요.

4. AUTO 모드가 동작하지 않을 때

  • 무선 연결 상태, 위치 권한 '항상 허용', 정확한 위치 사용, 배터리 제한 해제를 차례로 확인해 주세요.

  • 지도 데이터를 받았는지 확인해 주세요. 「지도 데이터를 받을 수 없습니다」 또는 「다운로드 실패」가 표시되면 인터넷 연결을 확인한 뒤 다시 받아 주세요.

  • AUTO 규칙을 추가하거나 바꾼 뒤 「설정 저장」을 눌렀는지 확인해 주세요.

  • 터널·속도 조건은 GPS 신호가 약한 곳에서 늦게 동작할 수 있습니다.

  • 「모드 보호 AUTO」(현재 모드 조건)는 지정한 모드가 아닐 때는 동작하지 않습니다.

5. 저장 또는 업데이트가 안 될 때

  • 기기 등록 또는 업데이트 안내가 표시되면 먼저 완료해 주세요.

  • 검사잠금이 켜져 있으면 모드 변경이 되지 않습니다. 상세 설정에서 해제해 주세요.

  • USB-C 케이블이 흔들리거나 헐겁지 않은지, 차량 시동 / ACC 전원이 OFF인지 확인해 주세요.

  • 업데이트 중에는 전원을 조작하지 말고 케이블도 분리하지 마세요. 문제가 반복되면 고객센터로 문의해 주세요.

제 12 장. 고객 지원

  • 기기 등록 고객은 앱을 통한 업데이트와 제품 점검 안내를 받을 수 있습니다.

  • 침수, 임의 개조, 배선 훼손, 과전압, 잘못된 장착으로 인한 고장은 유상 수리 대상이 될 수 있습니다.

  • 앱 조작은 반드시 정차 후 안전한 상태에서 진행해 주세요.

  • 메뉴의 「코드 입력」은 서비스 점검용입니다. 고객센터 안내가 있을 때만 사용해 주세요.
