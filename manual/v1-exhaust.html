N 배기밸브 컨트롤러 사용 설명서

배기밸브 컨트롤러 · PC 프로그램 · 차량 내 조작

중요 안내

차량 장착 전 PC 프로그램(또는 N Controller Mobile 앱의 USB 연결)으로 기기 등록과 최신 업데이트를 먼저 완료해 주세요. 펌웨어가 최신이 아니면 앱과 무선 연결을 사용할 수 없습니다. 등록된 기기는 추후 점검, 업데이트 안내, A/S 안내를 더 원활하게 받을 수 있습니다.

제 1 장. PC 프로그램 사용법

1. 프로그램 시작 및 기기 연결

  • 컨트롤러 케이스를 열고 내부 USB 포트에 케이블을 연결합니다.

  • N 밸브 컨트롤러 (PC) 프로그램을 실행한 뒤 USB 케이블로 컨트롤러와 PC를 연결합니다.

  • 정상 연결 시 화면 상단에 닉네임, 장치 종류, 현재 상태가 표시됩니다.

  • 처음 연결하는 기기는 신규 등록 창이 나타납니다. 사용할 닉네임을 입력하고 등록을 완료해 주세요.

  • 배기 컨트롤러는 프로그램에서 자동으로 배기밸브 컨트롤러로 식별됩니다.

  • PC가 없으면 휴대폰의 N Controller Mobile 앱과 USB-C 데이터 케이블로도 기기 등록, 업데이트, 설정을 할 수 있습니다. (앱 사용 설명서 참고)

2. 업데이트

  • 컨트롤러 기능을 최신 상태로 유지하는 기능입니다.

  • 업데이트가 필요한 경우 메인 화면에서 업데이트 버튼이 활성화됩니다.

  • 업데이트는 USB 연결에서만 진행됩니다. 무선(블루투스) 연결로는 업데이트할 수 없습니다.

  • 업데이트 중에는 USB 케이블을 분리하거나 PC 전원을 끄지 마세요.

  • 업데이트 실패 시 USB 케이블, 포트, 드라이버, 인터넷 연결 상태를 먼저 확인해 주세요.

3. 상세 설정

  • 메인 화면의 상세 설정 버튼을 누르면 배기밸브 동작과 LED 표시를 조정할 수 있습니다.

  • 상단 프리뷰 이미지를 클릭하면 설정값을 저장하기 전에 화면에서 LED 표시를 미리 확인할 수 있습니다.

  • 설정 변경 후에는 반드시 설정 저장 후 닫기 버튼을 눌러야 기기에 저장됩니다.

제 2 장. 차량 내 기본 조작법

1. 모드 변경

  • 버튼을 짧게 1회 누를 때마다 설정된 순서에 따라 모드가 변경됩니다.

  • 3단 모드 기본값은 순정 → 닫힘 → 열림 → 순정 반복입니다. 2단 모드를 사용하면 선택한 두 모드만 서로 전환됩니다.

  • 사전 점멸이 켜져 있으면 바뀔 모드의 색으로 LED가 2회 깜빡인 뒤 밸브가 작동합니다. 순정으로 바꿀 때는 사전 점멸이 없습니다.

  • 사전 점멸이 꺼져 있으면 버튼을 누르는 즉시 LED가 바뀔 모드로 표시되고, 약 1.5초 뒤 밸브가 움직입니다.

  • 밸브가 움직이기 전에 버튼을 다시 누르면 다음 모드로 넘어가며, 마지막으로 선택한 모드로 작동합니다.

  • 버튼을 2초 이상 눌렀다 떼면 모드는 바뀌지 않습니다. 시동 직후 약 1초 동안은 버튼으로 모드를 바꿀 수 없습니다.

  • 2단 조합에 없는 모드를 시동 모드로 고르면 그 조합의 첫 모드로 시작합니다. 닫힘 ↔︎ 열림 조합은 닫힘, 나머지 조합은 순정입니다.

2. 매너모드

  • 시동 모드를 매너모드로 설정하면 시동을 걸 때 밸브가 닫힘 상태로 시작하고 초록 LED가 빠르게 맥동합니다. 이른 아침이나 주거지역에서 조용히 출발할 때 사용하면 좋습니다.

  • 설정한 시간(1분 / 3분 / 5분)이 지나거나 버튼을 한 번 누르면(짧게·길게 모두) 시동을 끄기 전 마지막으로 쓰던 모드로 사전 점멸 없이 바로 돌아갑니다.

  • 앱 화면이나 위젯에서 모드를 눌러도 버튼을 누른 것과 같이 매너모드가 끝납니다.

  • 매너모드 중에는 설정 메뉴에 들어갈 수 없고 밸브 고착 방지도 동작하지 않습니다.

  • 매너모드 LED는 색 설정과 관계없이 항상 초록이며, 밝기는 닫힘 LED 밝기와 미등 연동 설정을 따릅니다.

3. 밸브 고착 방지 동작

  • 설정한 주기(30분 / 1시간 / 2시간)마다 LED가 현재 모드의 색으로 5회 깜빡인 뒤 밸브가 약 2초 동안 반대로 움직였다가 원래대로 돌아옵니다. 전체 동작은 약 4초 걸립니다.

  • 이 동작 중에는 버튼 입력이 잠시 무시됩니다.

  • 주기는 시동을 건 때(또는 설정 메뉴에서 저장한 때)부터 셉니다. 한 번 운행 시간이 주기보다 짧으면 동작하지 않습니다.

  • 순정 모드, 매너모드, 검사 잠금 중이거나 설정 메뉴 안에서는 실행되지 않습니다. 그동안 주기가 지났다면 닫힘 · 열림 상태가 되는 즉시 실행됩니다.

제 3 장. 차량 내 수동 설정 메뉴

사용 안내

PC 연결이 어려운 상황에서 버튼만으로 주요 설정을 변경할 수 있습니다. 더 세부적인 설정은 PC 프로그램 또는 앱 사용을 권장합니다.

  • 메뉴 진입: 버튼을 약 5초 이상 길게 누릅니다. LED가 노랑으로 빠르게 5회 깜빡인 뒤 2회 더 깜빡이며 수동 설정 메뉴로 들어갑니다.

  • 다음 값 보기: 버튼을 짧게 누릅니다. 약 0.4초 뒤 값이 바뀌며, 마지막 값 다음에는 처음 값으로 돌아갑니다.

  • 현재 값 확정 후 다음 메뉴: 버튼을 2초 길게 누릅니다. 초록이 잠깐 켜진 뒤 2회 깜빡이면 바로 손을 떼 주세요.

  • 빠르게 두 번 누르기: 지금 보이는 값 그대로 다음 메뉴로 넘어갑니다(2초 누르기와 같음).

  • 메뉴 안에서 버튼을 5초 이상 계속 누르고 있거나 30초 동안 입력이 없으면 저장하지 않고 메뉴를 나갑니다. 나갈 때 LED가 빠르게 5회 깜빡입니다.

  • 메뉴는 항상 M0부터, 현재 저장된 값으로 시작합니다. 메뉴 안에 있는 동안 밸브는 현재 모드 그대로입니다.

  • 모드 변경 대기(사전 점멸 · 1.5초) 중, 매너모드 중, 고착 방지 동작 중에는 메뉴에 들어가지지 않습니다.

  • 색상, 모드 방식(순서 · 2단), 커스텀 패턴 모양, 커스텀 속도 값은 버튼 메뉴로 바꿀 수 없으니 PC 프로그램이나 앱에서 바꿔 주세요.

  • M2에서 고른 효과에 따라 나오는 메뉴: 고정 점등 → M6 / 숨쉬기 → M3 → M4B → M5B → M6 / 심장박동 → M4P → M4S → M5P → M5S → M6 / 커스텀 패턴 → M4S → M5P → M5S → M6

  • 모드 방식이 「3단 순정 → 닫힘 → 열림」일 때만 M1_1 = 닫힘, M1_2 = 열림입니다. 그 밖의 모드 방식에서는 M1_1 = 열림, M1_2 = 닫힘이며, 각 메뉴는 그 모드에 설정한 색으로 켜집니다.

제 4 장. 부가 기능

1. 검사 잠금 모드 (닫힘 고정)

  • 정기 검사 등 밸브를 닫힘 상태로 유지해야 하는 상황에서 사용하는 기능입니다.

  • 버튼을 누른 채로 전원을 켜고 약 1초간 계속 누르고 있으면 기능이 켜지거나 해제됩니다. 켜지면 빨간 LED가 5회, 해제되면 초록 LED가 5회 깜빡입니다.

  • 앱 상세 설정 > 고급 기능의 「검사 잠금 모드」로도 켜고 끌 수 있습니다.

  • 기능이 켜지면 밸브가 닫힘 상태로 유지되고 LED는 꺼집니다. 버튼 조작(모드 변경 · 설정 메뉴)이 모두 동작하지 않고, 앱에서도 모드 변경과 설정 저장이 막힙니다.

  • 설정은 시동을 껐다 켜도 유지되며, 해제하면 설정한 시동 모드로 다시 동작합니다.

  • LED가 꺼져 있고 버튼이 반응하지 않으면 검사 잠금이 켜져 있는지 먼저 확인해 주세요. 시동을 걸 때 버튼이 눌려 있으면 의도치 않게 켜지거나 꺼질 수 있습니다.

2. 자동 밝기 조절 (미등 연동)

  • 미등 연동이 켜져 있으면 차량 미등이 켜졌을 때 LED가 어두워지며, 가장 어둡게는 약 3%까지 내려갑니다. 미등을 끄면 설정한 밝기로 돌아옵니다.

  • 컨트롤러가 차량 미등 신호에 맞춰 밝기 범위를 스스로 맞춥니다. 별도의 주변 밝기 센서는 사용하지 않습니다.

  • 사전 점멸과 고착 방지 안내 깜빡임은 미등 연동과 관계없이 일정한 밝기입니다.

3. 시동 시 자동 복구

  • 시동을 걸 때 전압이 순간적으로 떨어져 컨트롤러가 멈추면 약 2초 안에 스스로 다시 시작하고 설정한 시동 모드를 다시 적용합니다.

  • 이 과정은 자동으로 진행되며 별도 조작은 필요 없습니다. 이상이 반복되면 사용을 중지하고 고객센터에 문의해 주세요.

4. 버튼 보호

  • 버튼이 30초 넘게 눌린 채로 있으면(버튼 걸림 등) 그때부터 버튼 입력을 무시합니다. 설정 메뉴 중이었다면 저장하지 않고 닫습니다.

  • 모드는 그대로 유지되며, 버튼이 풀리면 정상으로 돌아옵니다.

5. 무선(블루투스) 연결

  • 무선 모듈이 설치된 컨트롤러는 N Controller Mobile 앱으로 모드 변경과 설정을 할 수 있습니다.

  • 앱 화면이나 위젯에서 모드를 누르면 기기 버튼과 똑같이 동작합니다(사전 점멸, 약 1.5초 뒤 작동, 매너모드 해제). AUTO 모드처럼 앱이 특정 모드를 직접 지정할 때만 사전 점멸 없이 바로 바뀝니다.

  • 무선 이름(3~20자)과 비밀번호(숫자 4자리) 등록은 USB로 연결한 상태에서 앱 안내에 따라 진행합니다. 자세한 내용은 앱 사용 설명서를 참고해 주세요.

  • PC 프로그램이나 앱이 USB로 컨트롤러와 통신하는 동안에는 무선으로 모드 변경, 설정 저장, 검사 잠금 변경을 할 수 없습니다. USB 연결을 끝내고 몇 초 뒤 다시 시도해 주세요.

  • 검사 잠금 중에는 앱으로도 모드를 바꿀 수 없습니다.

  • 펌웨어 업데이트는 무선으로 할 수 없으며, 반드시 USB로 연결해 진행해 주세요.
